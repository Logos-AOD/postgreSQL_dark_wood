# Анализ поведения игроков в игре «Секреты Тёмнолесья»

Учебный исследовательский проект на основе базы данных онлайн-игры **«Секреты Тёмнолесья»**.  
Цель — изучить, как характеристики игроков и их персонажей влияют на покупку  
внутриигровой валюты «райские лепестки», а также оценить активность игроков  
при совершении внутриигровых покупок.

## Задачи исследования

1. **Доля платящих игроков** — определить долю платящих пользователей по всем данным и в разрезе расы персонажа.
2. **Статистика внутриигровых покупок** — рассчитать статистические показатели по полю `amount`: среднее, медиану, минимум, максимум, стандартное отклонение.
3. **Аномальные нулевые покупки** — выявить и проанализировать покупки с нулевой стоимостью.
4. **Популярные эпические предметы** — определить топ предметов по количеству и сумме покупок, оценить поляризацию спроса.
5. **Зависимость активности от расы** — исследовать, как раса персонажа влияет на активность и средний чек игрока.
6. **Статистика по странам, классам и полу** — выявить типичный портрет игрока и различия в покупательском поведении.

## Данные

Источник — учебная база данных онлайн-игры **«Секреты Тёмнолесья»**.  
Все таблицы хранятся в схеме `fantasy`:

| Таблица | Что хранит |
|---|---|
| `users` | Информация об игроках: `id`, `race_id`, `class_id`, `loc_id`, `pers_gender`, `payer` |
| `events` | Информация о внутриигровых покупках: `transaction_id`, `id`, `item_code`, `amount` |
| `skills` | Информация о легендарных умениях персонажа |
| `race` | Информация о расе персонажа: `race_id`, `race` |
| `classes` | Информация о классе персонажа: `class_id`, `class` |
| `country` | Информация о стране регистрации игрока: `loc_id`, `location` |
| `items` | Информация об эпических предметах: `item_code`, `game_items` |

Ключевые поля, использованные в анализе:

| Поле | Описание |
|---|---|
| `id` | Идентификатор игрока |
| `payer` | Признак платящего игрока (0 / 1) |
| `race` | Раса персонажа (Human, Hobbit, Orc, Elf, Demon, Angel, Northman) |
| `class` | Класс персонажа (Knight, Paladin и др.) |
| `location` | Страна регистрации игрока |
| `pers_gender` | Пол персонажа |
| `item_code` / `game_items` | Код и название эпического предмета |
| `amount` | Стоимость покупки в «райских лепестках» |
| `transaction_id` | Идентификатор транзакции |
